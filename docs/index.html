metadata-gen

A CLI that generates metadata (OG) images and a full favicon set from what your project already has.

Runs locally. No API keys. Preview, refine, download into your repo.

Installation

$ npx metadata-gen init $ npx metadata-gen

Run these in your terminal, or copy a prompt for your AI coding tool.

What you get

Fully customizable metadata image and favicon set.

How it works

  1. 01ScanTitle, tagline, colors, and logo from package.json, README, CSS variables, Tailwind themes, token files, and logo.svg. Read-only.
  2. 02GenerateThree layouts and the favicon set, in a local preview.
  3. 03RefineTweak colors, text, logo. Download to public/metadata/.
